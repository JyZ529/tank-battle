# 坦克大战 · Battle City

一款使用原生 HTML + Canvas 实现的经典《坦克大战》(Battle City) 风格网页游戏，无需任何依赖，双击打开即可游玩。

## ✨ 特性

- 🎮 经典 13×13 战场地图，含砖墙、钢墙、河流等元素
- 🚀 玩家坦克 + 敌方坦克 AI（随机移动与射击）
- 🧱 可摧毁的砖墙、不可摧毁的钢墙
- 🦅 需要守护的基地（老鹰），被摧毁即游戏结束
- 📈 分数、关卡、生命系统，敌人随关卡逐渐变强
- 💥 爆炸粒子特效、屏幕震动、出生保护
- 🔊 使用 Web Audio API 生成音效，无需音频文件

## 🕹️ 操作方式

| 按键 | 功能 |
| --- | --- |
| `W` `A` `S` `D` 或 方向键 | 移动坦克 |
| `空格` 或 `J` | 射击 |
| `P` | 暂停 / 继续 |
| `回车` | 开始 / 重新开始 |

## 🚀 运行方式

直接用浏览器打开 `index.html` 即可，或者启动一个本地服务器：

```bash
# 方式一：Python
python -m http.server 8000
# 访问 http://localhost:8000

# 方式二：Node.js
npx serve
```

## 🎯 游戏规则

1. 操控坦克消灭所有敌方坦克即可过关。
2. 保护底部中央的基地（老鹰），基地被摧毁或生命耗尽则游戏结束。
3. 砖墙可被子弹摧毁，钢墙不可摧毁。
4. 每关 12 个敌人，击毁全部敌人即可进入下一关。

## 🛠️ 技术实现

- 纯原生 JavaScript，基于 Canvas 2D 渲染
- `requestAnimationFrame` 游戏循环
- 网格碰撞检测、AABB 坦克碰撞
- Web Audio API 程序化音效
